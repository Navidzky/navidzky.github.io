Haul Line

A budgeted bipartite-matching game

Connect mines to factories by dragging haul lines between them — but a fixed budget makes it impossible to wire up every mine, so the real problem is choosing which subset to connect. Submit your plan and an exact search reveals the true optimum, so you can see exactly where a cheaper combination was hiding. It's the same bipartite matching machinery behind the classic Monge transport problem I work with in my research, with a spending cap bolted on to make the trade-offs concrete.
